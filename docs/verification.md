# 動作確認記録

確認日：2026年11月6日。AI支援による提出用コピーの確認です。

## 環境

- macOS / Python 3.13.16
- Flask 3.1.3
- mysql-connector-python 26.10.0
- MySQL 26.7.0（既存DBとは別の一時DB）
- ブラウザ表示：Google Chrome（自動撮影）

## 確認結果

Flaskのテストクライアントを実際の一時MySQLに接続して確認しました。

| 確認内容 | 結果 |
| --- | --- |
| 一覧画面の表示 | HTTP 200 |
| 空白だけのエラー名・文字数超過 | フォーム再表示 |
| 正常な登録 | リダイレクト後、検索結果で記録を確認 |
| キーワードとカテゴリを組み合わせた検索 | 対象の記録を表示 |
| 一致する記録がない検索 | 0件時の表示を確認 |
| 詳細表示 | HTTP 200 |
| 編集 | 更新後の詳細に変更した値を表示 |
| 削除 | 削除後の詳細は404 |
| 存在しないIDの詳細・編集 | HTTP 404 |
| GETでの削除要求 | HTTP 405 |

ブラウザで一覧・詳細・入力エラー画面を開き、画面画像を保存しました。画像中の内容は動作確認用のサンプルです。
