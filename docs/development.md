# 制作・学習記録

## 現時点で取り組んだ学習

2026年11月6日、コードを参照しながら登録処理の流れを確認しました。

- HTMLの `name` と、Pythonで入力を取り出すキーの対応
- `strip()` による前後の空白除去
- 入力不備をリストに入れ、エラーが0件の場合にDBへ進む分岐
- INSERTの列と、渡す値の順序
- `commit()` による書き込みの確定
- 完了メッセージと一覧画面へのリダイレクト

入力に不備があるときは、書き込みを始めず、入力内容とエラーをフォームに渡す流れも確認しました。引き続き、各処理をコードと結びつけて学習しています。
